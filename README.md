# 🛒 نظام إدارة السوبرماركت المتكامل (Supermarket Management System)

نظام حديث وشامل لإدارة السوبرماركت ونقاط البيع (POS) والمخزون وحركة المبيعات وإدارة الصلاحيات والإعدادات متعددة اللغات، مبني بمعمارية حديثة تفصل بين واجهة المستخدم (**Frontend**) والخادم الخلفي (**Backend**)، ويعتمد على **Microsoft SQL Server 2025** وقواعد بيانات علائقية قوية عبر **TypeORM**.

## 🌟 أبرز التعديلات والمميزات الجديدة المضافة

### 1. 🔐 شاشة تسجيل الدخول والتحكم بالصلاحيات (Login & Role-based Routing):
- **شاشة دخول رئيسية** بالاسم أو البريد وكلمة المرور مع إمكانية الدخول السريع التجريبي بنقرة واحدة (Admin, Cashier, Customer).
- **توجيه ديناميكي للتبويبات (Tabs)** بناءً على دور المستخدم:
  - **المدير (Admin)**: كامل الصلاحيات لجميع الشاشات وإدارة المستخدمين والإعدادات.
  - **الكاشير (Cashier)**: نقطة البيع (POS)، حركة المبيعات، فواتير المبيعات والمرتجع، وتسجيل العملاء.
  - **العميل (Customer)**: متجر التسوق والتصنيفات، سلة المشتريات، وسجل فواتيره الشخصية فقط.
- **صفحة تسجيل عميل جديد (Register New Customer)** متاحة في شاشة الدخول وللكاشير في نقطة البيع.

### 2. ⚡ شاشة نقطة البيع (POS) المطوّرة:
- **شريط الأقسام مع قسم خاص للأصناف الشائعة (⭐ الأكثر طلباً وشيوعاً)** للوصول السريع للمنتجات الأكثر استهلاكاً.
- **بنود الفاتورة واضحة في منتصف الشاشة في شكل Grid منظم**:
  - عرض اسم الصنف، الباركود، سعر الوحدة، أزرار (+) و (-) لتعديل الكمية بسهولة.
  - **خصم منفصل لكل صنف على حدة (Item-level discount)** يخصم فورياً من البند.
  - **خصم عام على إجمالي الفاتورة كلها (Invoice-level discount)**.
- **تحديد وقت الشفت (نهاري ☀️ / ليلي 🌙)** وتسجيله مع الفاتورة.
- **ختم اسم بائع الفاتورة (الكاشير الحالي)** تلقائياً في بيانات الفاتورة والإيصال الحراري.
- **شاشة متابعة حركة المبيعات (Sales Analytics)**: إحصائيات المبيعات اليومية، مبيعات الشفت النهاري والليلي، أكثر المنتجات مبيعاً، وتدفق الفواتير.
- **نظام المرتجعات (Returns & Refunds)**: إمكانية إرجاع كامل الفاتورة أو إرجاع أصناف وكميات محددة، مع إعادة الكميات فورياً للمخزون وتسجيلها في سجل الجرد والـ Audit Log.

### 3. 🛡️ إزالة زر سكربت SQL Server:
- تم إزالة زر "سكربت SQL Server" بالكامل من واجهة النظام العلوية لتوفير مساحة أنظف للمستخدم.

### 4. 👥 شاشة إدارة المستخدمين والصلاحيات (Users & Permissions):
- شاشة خاصة بالأدمن لإنشاء وتعديل وحذف وتفعيل/تعطيل الكاشير والعملاء.
- تخصيص صلاحيات دقيقة بمربعات اختيار (Checkboxes):
  - إضافة منتجات جديدة (`canAddProduct`)
  - تسعير وتعديل المنتجات (`canEditPrice`)
  - حذف المنتجات (`canDeleteProduct`)
  - جرد وتدقيق المخزون (`canAuditInventory`)
  - إجراء المرتجعات (`canProcessReturns`)
  - إدارة إعدادات النظام (`canManageSettings`)

### 5. ⚙️ شاشة الإعدادات العامة (Settings):
- تعديل **اسم السوبرماركت** ليظهر في الهيدر والتقارير والفواتير فورياً.
- إضافة/تغيير **شعار الشركة (Logo)** مع معاينة مباشرة وظهوره أعلى الفاتورة الحرارية.
- اختيار **لغة المشروع**:
  - عربية (العربية - RTL)
  - إنجليزية (English - LTR)
  - فرنسية (Français - LTR)
  مع دعم تبديل الاتجاه والنصوص فورياً عبر قاموس الترجمات المدمج.
- اختيار وتحديد **العملة المستخدمة** (ج.م، ر.س، $، €، د.إ، د.ك، د.أ...) لتتغير في كل الأسعار والفواتير والتقارير.
